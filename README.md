# Portfólio Pessoal - Atividade Prática UNINTER

Este projeto consiste no desenvolvimento de um portfólio online pessoal como requisito para a disciplina de **Fundamentos da Programação Web**. O objetivo principal é aplicar conceitos de HTML5, CSS3 e JavaScript puro (Vanilla JS) para criar uma interface funcional e responsiva.

## 🛠️ Tecnologias Utilizadas

Para atender aos requisitos rigorosos da atividade, não foram utilizados frameworks ou bibliotecas externas:

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização personalizada e responsiva (sem frameworks como Bootstrap ou Tailwind).
* **JavaScript (Vanilla):** Implementação de interações, validação de formulários e lógica de tema.
* **VS Code:** Editor de código utilizado no desenvolvimento.

---

## 📋 Estrutura do Projeto

O site está organizado nas seguintes seções obrigatórias:

1.  **Sobre mim:** Apresentação pessoal, hobbies e informações gerais.
2.  **Formação:** Detalhes sobre educação acadêmica, cursos e idiomas.
3.  **Portfólio:** Exibição de projetos e trabalhos já realizados.
4.  **Contato:** Formulário funcional com validação via JavaScript.

### Funcionalidades Implementadas

* **Navegação:** Menu visível em todas as seções.
* **Validação de Formulário:** Verificação de campos obrigatórios e formato de e-mail antes do envio.
* **Interatividade:** _Alternância de tema claro/escuro e menu responsivo._
* **Simulação de Envio:** Limpeza de campos e mensagem de confirmação após o envio do formulário.
